# Imaging-and-Recovery-Lab

## Overview
A low-cost, low-resource imaging bench built to efficiently clone and deploy operating system images and backup data while using legacy computer hardware compatible with modern drives.

## Objective

To achieve a bare-metal drive cloning station using Clonezilla. This bench should be capable of rapid disk-to-disk cloning, master-image deployment for new hardware, creating reliable backups, and data recovery, all while maximizing the lifespan of legacy hardware.

## Lab Environment 

An HP Compaq DC5800 from 2008 running with just the motherboard, CPU, CPU cooler, RAM, PSU, and an 80gb HDD

2 GB of DDR2 memory
6 USB 2.0 ports - 30-45 MB/s bottleneck
Clonezilla Live
Legacy BIOS 
Rufus
